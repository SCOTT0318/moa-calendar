3. 외부 통신과 Google 권한

  • Google: 시스템 브라우저의 Google 인증 화면과 공식 OAuth·Gmail·Calendar API에 직접 연결합니다. 이메일 입력은 선택이며 새 Google 연결에서 비밀번호·앱 비밀번호·JSON 파일을 요구하지 않습니다.
  • 네이버: IMAP 메일 서버와 HTTPS CalDAV 캘린더 서버에 직접 연결합니다. Windows CalDAV의 실제 계정 호환은 별도 확인이 필요합니다.
  • 하이웍스: POP3 메일 서버에 직접 연결하며 서버의 메일 사본을 삭제하지 않습니다. 캘린더 연결은 제공하지 않습니다.
  • 기존 Google 앱 비밀번호 계정: 이전 연결을 보존한 경우 Google IMAP을 계속 사용할 수 있습니다. 브라우저 승인으로 전환할 수 있습니다.

연결 계정의 인증과 조회·저장을 위해 계정 제공자에게 필요한 인증 정보와 요청을 전송합니다. 제공자는 자체 정책에 따라 요청을 처리합니다. 모아가 Gmail 데이터를 네이버·하이웍스로 복사하거나 계정 데이터를 개발자의 별도 서버로 업로드하는 기능은 없습니다.

계정 옆 연결 기능 변경에서 메일·캘린더·쓰기 사용 여부를 바꾸고 같은 계정으로 재승인할 수 있습니다. 끈 기능의 데이터는 앱 목록에서 제거하며 쓰기를 끄면 원격 저장을 차단합니다. 변경 취소나 다른 계정 승인으로 확인이 실패하면 기존 연결을 유지합니다. 앱의 기능을 끄는 것과 Google 서버 권한의 철회는 별개입니다.

4. 연결 해제·권한 철회·삭제

  1. 이 PC의 계정 연결 중단: 설정의 해당 계정에서 연결 해제를 선택합니다. 그 계정의 로컬 로그인 정보를 지우고 현재 메일함·달력 목록에서 해당 계정 데이터를 제거합니다. 다른 연결 계정과 내 일정은 유지합니다.
  2. Google 서버의 앱 권한 철회: Google 계정의 연결된 앱 관리 안내에 따라 모아에 부여한 접근 권한을 삭제합니다. 모아의 연결 해제는 Google 서버의 권한 철회를 자동 수행하지 않습니다.
  3. 내 일정 삭제: 앱에서 해당 로컬 일정을 삭제합니다. Google·네이버에 이미 저장한 원격 일정의 삭제는 해당 제공자 캘린더에서 수행합니다.
  4. 이 PC의 보관 데이터 전체 삭제: 트레이의 종료로 모아를 완전히 끝낸 뒤 위 데이터 폴더를 삭제할 수 있습니다. 직접 만든 내 일정과 모든 계정 연결·설정도 함께 사라집니다. 이전 Data나 별도 백업은 따로 관리해야 합니다. 이전 Data 원본을 남기면 다음 실행 때 다시 가져올 수 있습니다.

앱 제거만으로 사용자 데이터 폴더는 삭제되지 않습니다. 설치·업데이트·앱 제거는 계정·내 일정·설정을 보존합니다. 로컬 파일 삭제나 계정 연결 해제로 Google·네이버·하이웍스의 원본 메일과 원격 일정이 삭제되지는 않습니다.
